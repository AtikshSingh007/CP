## Problem Statement

<div class="header"><div class="title">A. Hey, It's Me, Souvlakity</div><div class="time-limit"><div class="property-title">time limit per test</div>1 second</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>Souvlakity and Kalamakity are playing yet another game.</p><p>All the integers from $$$1$$$ to $$$n$$$ have been distributed between the players. The distribution can be represented as a binary string $$$s$$$ of size $$$n$$$, where $$$s_i = 1$$$ if integer $$$i$$$ has been given to Souvlakity, and $$$s_i = 0$$$ if it has been given to Kalamakity. It is guaranteed that Souvlakity owns at least one integer initially (there exists a $$$1$$$ in $$$s$$$).</p><p>The game will go on for $$$10^{100}$$$ turns. The two players play in alternating turns, with Souvlakity playing first.</p><p>When it is a player's turn, they must choose exactly one of their integers and give it to the other player. It can be shown that this is always possible under this game's constraints.</p><p>After all $$$10^{100}$$$ turns are finished, Souvlakity calculates his score as the range of the integers he owns (that is, his score is $$$\max(S) - \min(S)$$$, where $$$S$$$ is the set of integers he owns). It can be shown that Souvlakity will own at least one integer at the end of the game.</p><p>Souvlakity wants to maximize his score, and Kalamakity wants to minimize Souvlakity's score. What is Souvlakity's final score if both players act optimally?</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The first line contains the number of test cases $$$t$$$ ($$$1 \le t \le 100$$$). The description of the test cases follows.</p><p>The first line of each test case contains a single integer $$$n$$$ ($$$2 \le n \le 100$$$).</p><p>The second line of each test case contains a binary string $$$s$$$ of length $$$n$$$. It is guaranteed that there exists at least one $$$\mathtt{1}$$$ in $$$s$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, on a separate line, output a single integer: Souvlakity's final score after the game ends, if both players act optimally.</p></div><div class="sample-tests"><div class="section-title">Example</div><div

## Problem Statement

<div class="header"><div class="title">C. Maximize the Score</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>You are given an array $$$a$$$ of length $$$2n$$$. Each integer from $$$1$$$ to $$$n$$$ occurs exactly twice in $$$a$$$.</p><p>Initially, your score is $$$0$$$.</p><p>You can repeatedly perform the following operation while $$$a$$$ is non-empty:</p><ul> <li> Choose an integer $$$x$$$ that is present in $$$a$$$. </li><li> Let $$$l$$$ and $$$r$$$ be the indices of the leftmost and rightmost occurrences of $$$x$$$ in the current array, respectively. If $$$x$$$ occurs only once, then $$$l = r$$$. </li><li> Add $$$(r - l + 1)^2$$$ to your score. </li><li> Delete the elements $$$a_l, a_{l + 1}, \ldots, a_r$$$ from $$$a$$$. The remaining elements are concatenated without changing their order and re-indexed starting from $$$1$$$. </li></ul><p>Find the maximum possible score after making the array empty.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. over all test cases does not exceed $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, output a single integer — the maximum
